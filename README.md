## 🚀 Overview

**GoMi** is a modern, privacy-first desktop learning environment powered by Electron, React, TypeScript, and state-of-the-art LLMs. Unlike standard chat assistants that give away answers immediately, GoMi acts as a genuine tutor:

- 🧠 **Socratic Pedagogy**: Guides you toward answers through targeted questions, hints, and conceptual scaffolding.
- 🎯 **Dynamic Learning Plans**: Breaks down your goals into structured curricula with prerequisite-gated tasks, tracking mastery in real-time.
- 📖 **Text Guide Mode**: Dedicated voice-less, step-by-step guided learning with interactive checks and hints alongside the chat.
- 🎛️ **Interactive Tools Marketplace**: Renders hot-swappable visual sandboxes (such as logic circuit builders and physics simulators) directly inside chat sessions.
